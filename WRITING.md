# Editing content

Edit the centralized configuration in `assets/content.js`, then run `npm run build` and `npm test`. Preview using `npm run preview`. Page structure is in `scripts/build.mjs` and presentation in `style.css`.

Preserve the distinction between professional experience and representative concepts. Use synthetic data for simulations. Keep employer and client names, confidential details, unsupported outcomes, and repository links out of public content. All connection actions use the exact LinkedIn URL in the profile configuration. Review the generated `index.html` before publishing.
